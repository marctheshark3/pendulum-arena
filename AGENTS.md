# Pendulum Arena

This is a public benchmark registry and browser playground. Preserve source
attribution and distinguish author claims, artifact review, and independent
reproduction. Never manufacture a result or a timestamp. Never label the browser
toy a ranked benchmark. Never silently rewrite historical registry records.

Use `npm test` and `npm run check` before publishing. Keep credentials and private
runtime data out of the repository. Static application source is in `dist/`.
The registry contribution contract is in `CONTRIBUTING.md` and `docs/registry.md`.
