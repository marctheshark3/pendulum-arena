# Eighteen: original synthesis source and retained component evidence

This read-only inventory complements the independent eighteen qualification.
`source.tar.gz` contains original script/module bytes under `original/scripts`
and `original/src/rage_mill`. `retained.tar.gz` contains original component
arrays, receipts and bounded-owner/runtime history under `retained/`.
Both packets carry the same original-path/hash manifest, MIT license and credits.
The hash auditor uses only the Python standard library, extracts nothing, and
does not import the supplied scientific source. Run `python3 audit_packet.py
source.tar.gz` or use `retained.tar.gz` to inspect a packet's bytes.

The original scripts include count-aware mechanics/native derivatives, material
lifting from the seventeen donor, moving orbit, parking, bridge/feedback/value
design, exact hanging diagnostic and independent saved audits. Static import
edges plus the two computed runpy script edges are listed explicitly. Source
bytes were compared against the actual completed eighteen freeze's 1,111-file
clone inventory. The clone is source inventory, never a relocated execution
identity. Original absolute paths and owners in the manifest remain authoritative.

The retained bridge's IPOPT solve hit its bounded iteration limit. Its roughly
2.66999e-7 native cold-map gap is not feasibility or physical task success.
Actual exact diagnostic 3181040 and later independent calibration/development/
reserved qualification are distinct evidence. Classical native one-step affine
value feedback uses its own full 700-step zero-terminal tables, R=1000, at most
16 delivered-float32 native candidates. This is no JEPA policy or JEPA progress.

The first saved-model audit's runtime coverage failure and corrected second
owner are both preserved. Runtime manifests are provenance text only: native
libraries, CasADi serialized functions, generated C/JIT files, Python/runtime
executables, private Git history, old donor arrays and media are excluded.
No reproduction or reserved activation adapter is supplied. No fresh labels,
qualification rerun, reset distribution or portable numerical identity follows.
Fifty hertz denotes simulated action cadence, without a hardware deadline claim.
All owner clocks and original numeric bytes remain verbatim; archive headers
are normalized publication metadata, with actual packet creation in the manifest.
